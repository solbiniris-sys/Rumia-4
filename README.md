# 루미아 TRPG

혼자서도, 둘이서도 하는 역극 TRPG. 서버가 **GM이자 시나리오북**이 되어 장면을 보여주고, d20 판정을 굴리고, 결과를 기록합니다.

## 실행
```
npm install
npm start        # http://localhost:3000
```
Railway 등에 올릴 때는 볼륨을 붙이고 환경변수 `DATA_DIR` 에 그 경로를 지정하면 방이 유지됩니다. (저장 버전 5 — 이전 버전 방은 새로 시작)

## 폴더 구조
```
server.js            서버 (방 · 판정 · 저장)
rules.js             규칙 수치 (능력치 · 난이도 · 행운 · 경험치)
scenarios/           ← 시나리오를 여기에 .js 로 추가하면 자동 인식
  lumia_hogwarts.js  기존 루미아 120장면 (이식본)
  _lumia_import.json 이식된 장면 데이터 (직접 안 건드려도 됨)
  nightwatch.js      작성 예시 시나리오 (분기 · 성공/실패 · 조건 선택지)
public/              화면 (index.html · style.css · app.js)
```

## 플레이 방식
- **혼자**: 한 역할만 맡으면 됩니다. 상대 역할은 동행자(NPC)가 능력치에 맞게 자동 선택·판정하고, 역극에도 짧게 반응합니다.
- **둘이서**: 방 코드(또는 초대 링크)로 두 번째 오너가 들어오면 NPC 자리를 이어받습니다. 두 사람이 선택하면 함께 판정하고, 다음 장면은 둘 다 눌러야 넘어갑니다. 한 명이 오프라인이면 기다리지 않고 진행합니다.
- **역극**: 아래 입력창에서 대사/행동/서술로 자유롭게 이어 씁니다. 입력창에 `/r 통찰` 또는 `/r 2d6` 을 쓰거나 주사위 버튼으로 즉석 판정도 가능합니다.
- **잡담 탭**: 오너끼리의 OOC 대화. 역극 기록에는 남지 않습니다.
- **판정**: d20 + 능력치 ≥ 난이도(DC). 20 = 대성공(유대+1·마음+1), 1 = 대실패(마음−1). 선택지에 성공 확률이 표시됩니다. 행운(장당 3개)은 +4 보정.
- **능력치**: 마력·통찰·의지·친화·민첩, 총합 15점(각 1~6)을 배분. 레벨업 때 포인트 +1.
- **자원**: 체력 · 마음(0이면 모든 판정 −2) · 행운. 새 장(章)이 시작되면 일부 회복.

## 시나리오 작성법 (스토리는 나중에 이 파일만 늘리면 됩니다)
`scenarios/내시나리오.js` 를 만들면 로비에 자동으로 나타납니다. `nightwatch.js` 를 복사해서 시작하세요.
```js
module.exports = {
  id: 'my', title: '제목', blurb: '한 줄 소개',
  roles: { A: { name:'이름', sub:'설명', color:'#8fb3d9', preset:{MAG:2,INS:4,WIL:3,CHA:2,AGI:4} }, B: {...} }, // 합계 15
  items: { lamp: { name:'등불', desc:'설명' } },
  start: 'door',
  scenes: {
    door: { title:'장면 제목', kicker:'1막', text:['문단1','문단2'],
      choices: [                       // 배열 = 두 역할 공통 / {A:[...],B:[...]} = 역할별
        { label:'문틈을 살핀다', stat:'INS', dc:11,
          ok:   { text:'성공 묘사', fx:{ xp:1, flag:'seen' }, goto:'next_scene' },
          fail: { text:'실패 묘사', fx:{ hp:-1 },           goto:'next_scene' } },
        { label:'열쇠로 연다', req:{ item:'key' }, stat:'AGI', dc:9, say:'성공 대사', goto:'x' },  // 조건 선택지
      ] },
  },
};
```
- 장면: `title kicker text choices next if give dc ending npc gm`
- 선택지: `label stat dc tag req ok fail say fx goto`  (`stat` 이 없으면 판정 없이 통과)
- `fx`: `bond heart hp mind luck xp give:'아이템' flag:'플래그'`
- `req`: `item flag bond stat:{INS:4}` — 조건이 안 맞으면 선택지가 숨겨집니다. 장면의 `if` 도 같은 형식.
- `{A}` `{B}` 처럼 역할 키를 중괄호로 쓰면 플레이어가 정한 이름으로 바뀝니다.
- 두 사람이 동시에 판정하면 **총합이 높은 쪽의 `goto`** 로 이야기가 갈라집니다.
- 시나리오의 `gm: [...]`(GM 한마디), `npcLines: {역할키:[...]}`(솔로 동행자 대사)를 넣으면 역극 분위기가 풍부해집니다.

## 방 저장 (Render 등 무료 호스팅)
- 서버는 `rooms.json` 에 저장하지만, 무료 플랜은 재시작·재배포 때 파일이 지워집니다.
- 그래서 **접속한 기기(브라우저)에도 자동 백업**합니다. 서버가 방을 잃은 뒤 같은 기기로 다시 들어오면 "기기에 저장된 기록으로 복구해요" 안내와 함께 장면·소지품·유대·능력치·최근 기록이 되살아납니다. 상대 오너는 방 코드로 다시 들어오면 자기 자리를 이어받습니다.
- 한계: 백업은 최근 로그 120줄·잡담 60줄까지이고, 브라우저 데이터를 지우면 사라집니다.
- 완전한 서버 저장을 원하면 Render 유료 플랜의 Disk 를 `/data` 에 붙이고 환경변수 `DATA_DIR=/data` 를 지정하세요.
